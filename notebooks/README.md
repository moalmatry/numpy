# Notebooks

Organize study notebooks here in numerical order, for example:

- `00_getting_started.ipynb` — Environment check and array basics
- `01_arrays_and_dtypes.ipynb` — Array creation, shapes, dtypes, memory layout
- `02_indexing_and_slicing.ipynb` — Views vs copies, boolean & fancy indexing
- `03_ufuncs_and_broadcasting.ipynb` — Universal functions and broadcasting rules
- `04_aggregations_and_axes.ipynb` — Reductions, axis semantics, sorting
- `05_linear_algebra_and_random.ipynb` — `np.linalg` and `np.random.default_rng`
